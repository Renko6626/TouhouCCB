# FX 持仓指标与展示优先级

日期：2026-10-13。指标盘点基线：`2cbe5ae`。下文保留当时的字段盘点与取舍；最终展示方案已实施，见下述说明。

最终方案：FX 多空和 LMSR 持仓卡统一展示数量、持仓等效均价、预计平仓均价、预计所得或支出、预计平仓盈亏及百分比。卡片颜色按预计平仓盈亏判断，账面市值和账面盈亏放入详情。数量、金额显示 2 位小数，均价显示 4 位；FX 下单按钮显示动作、数量和支付或所得的整数约数。持仓关键数字及保证金率突出，订单预估保持紧凑。仅调整展示精度，计算和提交精度不变。

FX 持仓卡应当补回帮助用户判断仓位的信息。当前卡片只剩数量和盈亏，省掉了成本与平仓价格的对照，用户需要展开详情或填写订单才能回答“我买得贵不贵”“现在全卖能拿到多少”。建议恢复持仓数量、成本均价、预计全仓平仓均价，以及与该平仓报价同口径的盈亏。压缩重复文案和重复卡片，不能替代这些信息。

多头可以直接与 LMSR 的买入均价、预计卖出均价对应。空头的历史开空均价不能直接用现有剩余所得和含息欠币相除；应展示含息待还数量、预计回补均价及成本，避免为了多空对称而混用口径。

本文盘点对交易界面有实际用途的量，不枚举任意数学组合。没有用户行为统计，下面的“主要”依据用户需要完成的判断和指标是否改变交易决策排序，不宣称已经验证过点击率或使用频率。

## 1 用户最需要回答的问题

| 用户的问题 | 应首先给出的信息 | 不足以回答问题的信息 |
|---|---|---|
| 我现在持有什么、欠什么？ | 多头持仓数量；空头含息待还数量 | 买卖方向按钮、当前输入数量 |
| 我这笔仓位的成本是多少？ | 多头成本均价；成本总额可进详情 | 当前参考汇率 |
| 现在全部平仓，实际价格大概怎样？ | 对当前全仓数量计算的净卖出均价或含费回补均价 | 盘口参考价、小额 bid/ask、任意新订单的均价 |
| 现在平仓预计赚亏多少？ | 与全仓平仓报价配套的盈亏金额 | 单独的账面浮盈，或现金余额变化 |
| 平仓需要补现金吗？ | 空头回补成本、账户现金、现金缺口 | 把现金余额当成保证金允许支出的额度 |
| 下这笔订单会改变什么？ | 本笔预计所得或成本；跨零拆分；新增借款或欠币 | 当前全仓指标 |
| 我距离强平有多远？ | 当前全账户保证金率与维持门槛；本笔成交后保证金率 | 本次规模倍数、该币种单独盈亏 |

## 2 当前可用的信息

| 来源 | 已有字段或能力 | 能支持什么 | 不能直接证明什么 |
|---|---|---|---|
| 同币种多头账户基准 | `foreign_amount`、`cost_basis` | 当前数量、剩余成本、成本均价 | 已售仓位累计收益、该币种分摊的金圆券借款利息 |
| 同币种空头账户基准 | 借币本金、已计利息、计息时间、`proceeds_basis_gold` | 含息欠币、剩余开空所得、回补盈亏的成本基础 | 所有历史开空的原始加权均价 |
| 当前交易池输入 | 金圆券及外币储备、买卖费率、市场状态、版本与时间 | 当前参考汇率、指定数量的买卖报价 | 报价必定可成交、市场未来走势 |
| 本地报价函数 | 买入、卖出、买回指定数量；六位小数业务精度 | 全仓或部分平仓均价、手续费、成本和所得 | 借出库存、最终账户版本、提交时的价格保护已通过 |
| 全账户与规则 | 现金、金债、所有 FX/LMSR 仓位、利率、开仓和维持门槛 | 全账户净值、可用现金、保证金率及风险判定 | 把某笔金债一一对应到某个 FX 仓位 |
| 当前订单模拟 | 逐段买卖、借款、还款、订单后余额和全账户估值 | 本笔成本、所得、跨零、新增风险、成交后保证金率 | 历史累计收益 |
| 最近成交记录 | 当前币种最近 50 笔成交及分段信息 | 最近成交明细、指定记录的成交均价和手续费 | 完整生命周期的收益、总手续费、原始开仓均价 |
| K 线与实时成交 | OHLC、成交量、部分成交时间和价格 | 当前可用时间窗口内的走势和区间统计 | 从不足一日的可见数据推断完整 24 小时高低点或涨跌幅 |

账户与定价输入应来自同一交易会话的有效基准。市场状态必须一并检查；纯数学报价成功不代表当时允许卖出或回补。

## 3 指标口径与优先级

优先级分为：

- **主要**：在持仓卡、订单区或顶部账户栏常驻，直接帮助判断仓位、下单或风险。
- **辅助**：放详情或解释入口，帮助核对数字。
- **按条件显示**：只在发生借款、跨零、资金不足、异常或额外现金需求时出现。
- **暂不展示**：当前无法可靠得到，或用户意义尚不明确。

### 3.1 行情与价格

设当前池金圆券储备为 `G`，外币储备为 `F`，参考汇率为 `P = G / F`。所有单位价格统一为“金圆券 / 1 外币”。

| 可构造的量 | 定义或来源 | 重要限制 | 推荐位置 |
|---|---|---|---|
| 当前参考汇率 | `G / F` | 边际价格，不是全仓成交均价 | 主要，页面顶部已有 |
| 小额买入参考价 | 近似 `P / (1 − 买入费率)`；也有公开 snapshot ask | 近似极小订单，不能当持仓买入成本 | 辅助，不占持仓卡 |
| 小额卖出参考价 | 近似 `P × (1 − 卖出费率)`；也有公开 snapshot bid | 不是全仓卖出的均价 | 辅助 |
| 参考买卖价差 | 小额 ask − bid；比例可除以 `P` | 包含费用，不代表只有流动性损耗 | 辅助 |
| 指定订单的成交均价 | 买入总金圆券 / 外币所得；卖出金圆券所得 / 外币投入 | 按订单或单独交易腿计算，含相应费用 | 主要，订单区 |
| 均价相对参考价偏离 | 按现有 `tradeSlippageBps` 口径比较均价与 `P` | 含费用和订单自身价格影响；不等于报价变动容忍度 | 辅助；显著偏离时提示 |
| 24 小时成交额 | 现有 `volume_24h` | 交易活跃度，不是个人收益 | 页面行情区已有 |
| 数据更新时间与可用状态 | 会话、报价、行情时间与状态 | 时间新不自动代表全账户估值完整 | 常态简短显示，异常明显提示 |

### 3.2 多头持仓

设当前外币持仓为 `Q`，剩余金圆券成本为 `C`，全仓净卖出所得为 `V_sell = quoteFx('sell', Q).output_amount`。全仓报价必须使用当前池输入，卖出手续费已经体现在净所得中。

| 可构造的量 | 定义 | 能回答的问题或限制 | 优先级 |
|---|---|---|---|
| 持仓数量 | `Q` | 我现在持有多少 | 主要 |
| 持仓成本 | `C` | 当前剩余仓位承担多少成本；不是全部历史投入 | 辅助 |
| 买入均价 | `C / Q` | 当前剩余仓位的加权成本，包含计入买入成本的费用 | 主要 |
| 账面市值 | `Q × P` | 按边际参考价估值，不代表全部可卖所得 | 辅助，或个人资产页 |
| 账面盈亏 | `Q × P − C` | 随参考价变动的未实现盈亏，不扣平仓价格影响 | 辅助，与平仓盈亏区分 |
| 账面盈亏比例 | `(Q × P − C) / C` | 成本为正时可算；不是账户本金收益率 | 辅助 |
| 预计全仓卖出所得 | `V_sell` | 当前全卖大概能取得多少金圆券，已扣报价中的卖出费用 | 主要，平仓按钮附近 |
| 预计全仓卖出均价 | `V_sell / Q` | 和买入均价比较；必须注明“预计全仓”，不是历史卖出均价 | 主要 |
| 预计全仓平仓盈亏 | `V_sell − C` | 与预计卖出均价一致，未分摊全账户金债利息 | 主要，持仓卡主盈亏 |
| 预计平仓盈亏比例 | `(V_sell − C) / C` | 用剩余成本作分母；不能写成自有本金回报率 | 主要，可紧邻金额 |
| 全卖相对账面估值的差额 | `Q × P − V_sell` | 费用和价格影响合计，不应全部称为手续费 | 辅助 |
| 全卖预计自动还金债 | 从全卖订单模拟的 `repaid_gold` 取得 | 自动还款不改变这笔资产交易的损益 | 按条件显示 |
| 全卖对可用现金的净影响 | 从全卖订单后的账户预估取得 | 所得可能先还债，不能把 `V_sell` 叫“可用现金到账” | 按条件显示 |

`Q = 0` 时不生成均价。`C = 0` 时盈亏金额仍可算，盈亏比例不展示；零成本均价可以显示为零，不能借用要求成本大于零的图表辅助函数把它误判为缺失。

全仓持仓卡报价与用户填写的卖出订单分别计算，二者不能共用金额：用户选择 25% 平仓时，持仓卡仍描述全仓，订单区描述本次 25%。

### 3.3 空头持仓

设未还外币本金为 `Q_principal`，当前含息待还数量为 `Q_debt`，账户现金为 `Cash`，剩余开空所得基础为 `S = proceeds_basis_gold`，全仓买回含费成本为 `K = quoteFx('buyExactOut', Q_debt).input_amount`。

| 可构造的量 | 定义 | 能回答的问题或限制 | 优先级 |
|---|---|---|---|
| 未还借币本金 | `Q_principal` | 本金与利息拆分 | 辅助 |
| 含息待还数量 | 当前本金与已计利息按当前时刻计息得到的 `Q_debt` | 真正需要买回归还的数量；利息近似要保留标识 | 主要 |
| 已计利息 | `interest_foreign` | 已加入欠币的利息，未必已经支付 | 辅助 |
| 待计利息 | `Q_debt − Q_principal − interest_foreign` | 从上次计息到报价时的新利息 | 辅助 |
| 剩余开空所得基础 | `S` | 当前剩余空头的盈亏成本基础；不等于现金余额 | 辅助 |
| 参考欠币价值 | `Q_debt × P` | 按边际价估算负债价值，不等于实际回补支出 | 辅助 |
| 参考账面空头盈亏 | `S − Q_debt × P` | 可计算，但与全仓回补盈亏不是同一个口径 | 辅助，不作为卡片主盈亏 |
| 预计全仓回补成本 | `K` | 全部归还当前含息欠币要花多少金圆券，含报价费用 | 主要 |
| 预计全仓回补均价 | `K / Q_debt` | 当前整个空头仓位的含费买回均价 | 主要 |
| 预计全仓平仓盈亏 | `S − K` | 与当前参考回补估值同口径，包含欠币利息的回补影响 | 主要 |
| 预计平仓盈亏比例 | `(S − K) / S` | 分母是剩余开空所得，不是用户自有本金，必须解释 | 辅助，先不与多头百分比强行对齐 |
| 含息成本参考价 | `S / Q_debt` | 与 `K / Q_debt` 对比能解释平仓损益；不是历史开空均价 | 辅助，命名确认后可考虑进卡 |
| 预计现金缺口 | `max(0, K − Cash)` | 全回补成本超过账户现金，需要先筹集现金 | 按条件显示，重要 |
| 回补时偿还的本金与利息 | 从当前含息欠币拆分，利息先还 | 部分回补优先归还利息，不能按本金占比随意分配 | 辅助或成交明细 |
| 固定利率下未来计息估计 | 以当前欠币及利率按指定时长计算 | 假设不交易、利率不变；不是已经产生的欠币 | 辅助，借款规则页 |

“预计全仓回补成本”是一笔数学和账户预估，不是“目前一定能回补”：市场状态、资金不足、数据缺失和成交保护仍可能阻止执行。欠币超过可买回容量时，成本和均价应显示不可估算或具体原因，不能填零。

#### 为什么不能直接展示历史开空均价

回补先归还外币利息，再还本金；剩余所得基础则按本次回补数量占含息总欠币的比例分摊。这两条更新规则不同。例如原本金 100、已计利息 10、所得基础 200，回补 10 后本金仍为 100，但所得基础约为 181.818182。此时 `S / Q_principal ≈ 1.818182`，不能称为原始开空均价 2。

`S / Q_debt` 可以定义为“含息成本参考价”，且有 `S − K = Q_debt × (S / Q_debt − K / Q_debt)`。它随利息和仓位变化更新，不是一个固定的历史成交价格，也不是边际市场价的精确保本线。

当前图表的空头持仓价格线也使用 `S / Q_debt`。把该线的数值搬进卡片前，应一起核对“空头均价”的图表标签，不能让同一个误导性的名称在两处出现。

### 3.4 当前订单

| 可构造的量 | 数据或计算方式 | 优先级及位置 |
|---|---|---|
| 本次投入数量或金额 | 输入与实际订单参数 | 主要，输入区 |
| 本次规模相对本金的倍数 | 金圆券参考规模 / 当前全账户清算净值 | 主要，滑条；不是成交后账户杠杆 |
| 卖出参考金额对应外币数量 | 参考金额 / 当前同组汇率，按业务精度换算 | 主要，金额输入时显示 |
| 本次预计买入、卖出所得或回补成本 | 当前订单或各交易腿报价 | 主要，报价区 |
| 本次含费成交均价 | 该腿金圆券与外币数量之比 | 主要，报价区；和持仓全仓均价分别命名 |
| 本次费用 | 各腿 `fee_amount` 及各自币种 | 辅助，报价小字；跨零时不可把不同币种的费用相加后配一个币种 |
| 现金与新增金债投入 | 现有资金分配与订单模拟 | 存在借款时主要；已知零值省略 |
| 新增借币数量与卖出所得 | `short_open` 交易腿 | 按条件显示，不能隐藏新增债务 |
| 回补后做多、卖出后做空的分段数量 | 当前净交易 `legs` | 跨零时主要 |
| 本次平仓对应成本及盈亏 | 多头按该卖出腿分摊成本；空头按本次含息归还比例分摊所得基础 | 平仓时主要；与全仓卡片分开 |
| 成交后剩余持仓或欠币 | `wallet_after`、`foreign_debt_after` | 按条件显示，部分平仓或跨零时有用 |
| 自动还款 | `repaid_gold` | 非零时显示，避免把所得当成全部可花用余额 |
| 成交后现金变化 | 订单模拟 `cash_delta` | 辅助；资金缺口时展开 |
| 成交后全账户保证金率 | 订单后全账户估值及风险基数 | 有借款时主要；成交保护下拉与确认弹窗 |
| 允许的最低所得或最高支出 | 已捕获报价加上所选容忍度；既有精度规则 | 成交保护下拉 |
| 本笔执行条件与异常 | 当前 `condition`、拒绝原因和未确认原因 | 异常时主要；同一问题只提示一次 |

持仓卡中的“预计全仓卖出均价”与订单区的“本次成交均价”是两个不同问题，即使一次全卖时数值相同，也不应合并数据来源。持仓卡只能使用纯平仓范围，不能把滑条跨零订单中新增空头的所得算进多头全仓平仓收益。

### 3.5 全账户

设全部可清算正资产为 `A`，金圆券含息债务为 `D`，全部空头回补成本为 `K_all`，现金为 `Cash`，规则杠杆参数为 `L`，`α = (L − 1) / L`。

| 可构造的量 | 定义或来源 | 推荐位置 |
|---|---|---|
| 全账户可用现金 | 统一现金余额；不等于保证金允许支出的额度 | 主要，顶部黑栏已有 |
| 账面净值 | 现金＋边际估值正资产−金债−边际估值欠币 | 辅助，资产页；与清算净值区分 |
| 清算净值 | `E = Cash + A − D − K_all` | 主要，顶部本金；有未知估值时不假定为零 |
| 全账户风险基数 | `B = max(D, α × A) + α × K_all` | 辅助，解释风控；不直接展示算法 |
| 当前保证金率 | `E / B` | 主要，顶部黑栏；无负债时显示“无负债” |
| 开仓门槛 | `1 / (L − 1)` | 用于真实准入判断；不在持仓卡反复展示 |
| 维持门槛 | 有效规则的 `maintenance_ratio` | 主要，顶部黑栏 |
| 维持要求的当前金额余量 | `E − maintenance_ratio × B` | 可定义但暂不常驻；只是当前快照，不是可承受未来亏损的保证 |
| 账户冻结、估值未知、低于门槛 | 会话及风险结果 | 异常时主要，不能被“健康”样式覆盖 |

界面展示的 `B` 有保守量化，准入用生产逻辑中未截断的量及误差范围。不能根据四舍五入后的百分比重新做风险判断，也不能把本次 2 倍规模写成“账户 2 倍杠杆”。

### 3.6 目前不应直接构造或承诺的量

| 想展示的量 | 缺口或误导风险 | 当前处理 |
|---|---|---|
| 空头原始历史开空均价 | 已有本金和所得基础在部分回补时不同步变化；最近 50 笔未必覆盖全历史 | 不直接用 `S / 本金` 冒充；若确实要做，应先定义完整历史或额外成本口径 |
| 该币种累计已实现盈亏 | 需要完整成交、成本分摊与利息归属 | 最近记录不能代表累计全部收益 |
| 该币种累计手续费 | 最近 50 笔不完整，且费用存在不同币种 | 不把多币种费用直接相加 |
| 扣除全部融资成本后的单仓收益 | 金债是统一账户债务，没有可靠的一一归属 | 当前平仓盈亏明确未分摊金债利息 |
| 用户自有本金收益率或 ROE | 持仓成本、开空所得、自有本金不是同一个分母 | 使用定义清楚的持仓盈亏比例，或暂不展示 |
| 精确强平价格或距离强平的涨跌幅 | 全账户多仓共同担保；AMM 回补成本非线性；利息和其他价格同时变化 | 不用简单单仓公式给确定数字 |
| 最大安全开仓量 | 会随全账户、价格曲线、库存与利息变化，不能由滑条上限直接推出 | 滑条仅选规模，具体订单继续逐笔风控 |
| “可立即成交”的全仓报价 | 本地预估无法提前确认提交时全部检查 | 用“预计”，错误时显示具体阻断原因 |
| 固定市场保本价 | 把均价等同边际价会漏掉价格影响、手续费与利息 | 多头成本均价只作成本参考，空头 `S / Q_debt` 也只作含息参考 |

## 4 与 LMSR 持仓面板对齐

现有 LMSR 卡片包含：持仓数量、当前边际价、账面市值、买入成本均价、预计全仓净卖出均价、账面浮盈及比例，以及带预计卖出所得的一键平仓按钮。账面浮盈是主显示，平仓口径的盈亏在悬浮说明中。

| LMSR 信息 | FX 多头对应 | FX 空头对应 | 对齐建议 |
|---|---|---|---|
| 持仓数量 | 外币持仓 `Q` | 含息待还 `Q_debt` | 都放在卡片首行，但空头明确是待还 |
| 买入均价 | `C / Q` | 无法直接对应可靠的历史开空均价 | 多头恢复；空头不硬凑同名数字 |
| 全仓卖出均价 | `V_sell / Q` | 全仓回补均价 `K / Q_debt` | 显示完整动作与全仓范围 |
| 当前边际价 | 顶部参考汇率 `P` | 同一个 `P` | 顶部和图表已显示，不再默认重复 |
| 账面市值 | `Q × P` | 欠币参考价值 `Q_debt × P` | 可进持仓详情，避免资产与负债名字相同 |
| 浮盈金额与比例 | 可采用账面或平仓口径 | 推荐平仓口径 | FX 主盈亏用预计全仓平仓值，与展示的平仓均价一致 |
| 一键平仓预计所得 | 全卖净所得 | 全回补支出 | 空头是支出，不能显示为到账所得 |

FX 与 LMSR 相似的重点是“数量＋成本和交易价格对照＋盈亏＋平仓动作”，不必复制 LMSR 所有字段或沿用其混合账面／平仓口径。现有 LMSR 两种盈亏口径并存，FX 补回信息时应把名称写清楚。

## 5 展示方案的取舍

| 方案 | 多头卡 | 空头卡 | 主要取舍 |
|---|---|---|---|
| 当前极简 | 数量、盈亏、平仓按钮 | 含息数量、盈亏、回补按钮 | 扫读快，但缺少成本与平仓价格对照；不推荐继续保持 |
| 关键指标卡，推荐 | 数量、成本均价、预计全仓卖出均价、预计平仓盈亏；按钮附近显示预计所得 | 含息待还数量、预计全仓回补均价、预计成本、预计平仓盈亏；需要时显示现金缺口 | 补回用户最关心的信息，金额和均价口径一致；多空不完全对称 |
| 完整复制 LMSR 密度 | 再加参考价、账面市值、账面盈亏 | 再加欠币市值、成本参考价、本金和利息 | 信息多，但与顶部及详情重复，容易混淆两种盈亏；不推荐全部常驻 |

### 推荐的多头卡

```text
多头持仓       买入均价          预计全仓卖出均价
300 摩拉       1.666667          1.900000

预计平仓盈亏   +70.00 金圆券  (+14.00%)
                               [卖出全部]
                               预计所得 570.00 金圆券

持仓详情：成本总额、账面市值、账面盈亏、口径说明
```

这是用于说明关系的假设数值：剩余成本 500、数量 300、当前全仓净卖出报价 570。实际手续费与价格影响已包含在该净报价里。颜色依据预计平仓盈亏，详情中的账面盈亏可以与其不同，不用账面盈亏给平仓金额着色。

### 推荐的空头卡

```text
待还（含息）    预计全仓回补均价    预计回补成本
60 摩拉        2.000000          120.00 金圆券

预计平仓盈亏   +10.00 金圆券
                               [全部回补]

需要补可用现金时：需补现金 X 金圆券
持仓详情：剩余开空所得、本金与利息、含息成本参考价
```

示例假设剩余开空所得基础为 130、全仓回补报价为 120。卡片不把 `130 / 60` 称为历史开空均价；也不把“账户现金减去回补支出”当成盈亏。空头盈亏比例暂放详情，避免用户把所得基础误认为自己的本金。

两张卡片都增加价格与金额信息，不恢复常驻说明段落。单位价格使用统一单位提示，数量与总额保留相应币种；手机可将三个指标排成两行，不能为了省字去掉“预计”“全仓”“含息”等关键限定。

## 6 页面上的职责分配

| 区域 | 应常驻的内容 | 避免重复的内容 |
|---|---|---|
| 顶部黑栏 | 当前汇率、全账户清算净值、可用现金、当前保证金率、维持门槛 | 每个持仓卡再重复全账户风险和本金 |
| 红绿持仓卡 | 当前仓位、持仓成本或待还量、预计全仓平仓价格、主盈亏、平仓动作 | 完整规则、技术检查原因、历史成交列表 |
| 本次订单区 | 输入规模、本次报价与均价、借款、平仓盈亏、跨零拆分 | 无变化地再复述当前全仓卡片 |
| 持仓详情 | 成本基础、账面估值、本金利息和口径解释 | 第二张完整持仓卡重复同一数量与盈亏 |
| 成交保护下拉 | 容忍度、最低所得或最高支出、成交后保证金率 | 再复述顶部维持门槛与全部借款规则 |
| 确认弹窗 | 本次新增金债或欠币、捕获的订单金额、成交后风险 | 当前全部历史与当前卡片的重复摘要 |

## 7 计算与展示边界

1. **均价必须标明范围。** 预计全仓平仓均价、本次订单均价、历史成本均价不可互换。
2. **持仓卡报价不等待填写订单。** 使用当前数量及同组池输入生成纯平仓预估，保留现有本地报价路线，不新增每次行情更新的服务端报价请求。
3. **同一张卡采用同一计算时点。** 价格、含息数量、平仓总额、均价和盈亏同步更新；不要混用公开行情旧价和交易会话新储备。
4. **费用单位不能丢失。** 买入和回补费用在金圆券侧，卖出费用在外币侧；均价和净所得已包含费用，不再重复扣费。
5. **显示量与准入分开。** 百分比只用于阅读，提交继续沿用既有风险检查、幂等处理、价格保护和借款确认。
6. **未知不等于零。** 输入、账户、池状态或全部回补估值缺失时显示“—”或具体不可估算原因；禁止填零并着正常收益色。
7. **亏盈颜色只对应所标注的盈亏。** 推荐主色与预计全仓平仓盈亏一致；本地预估仍不能当已实现收益。
8. **全回补继续包含成交时利息。** 卡片是当前时点估值，提交使用原有全回补语义，不把快照欠币数量固化为全部欠币。
9. **可算与可成交分开。** 可能有参考成本但现金不足、市场暂停或其他检查不通过，卡片不能标记为“可立即平仓”。
10. **暂停估值与交易行为分开。** 风控对不可卖资产采用的保守估值，不代表用户能按该金额卖出；卡片应说明交易状态。

## 8 建议的下一步

先确认关键指标卡的范围：多头恢复数量、买入均价和预计全仓卖出均价；空头增加预计全仓回补均价与成本；主盈亏统一采用预计全仓平仓口径，保留账面盈亏在详情中。

第一轮不加入历史开空均价、精确强平价格、单仓 ROE、累计收益和最大安全仓位。若以后确实需要，分别确认定义与数据来源，不从现有金额随意拼出看似精确的结果。

实现可以沿用当前账户基准、池输入、报价函数和侧栏结构；缺口主要是展示派生和一致命名，不需要新增定价模型或更改风控。上述优先级与卡片内容仍是待确认方案。
