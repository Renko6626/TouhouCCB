# FX 前端 UI/UX 改进记录

2026-09-30：先实现审查项 1–5，随后用户确认立即继续 6–10，并要求统一 FX / LMSR 移动端交易入口。FX 是主玩法，LMSR 为次要部分。

## 第一轮：1–5

- 按账户的传统 / 统一信贷模式解释抵押、负债买入与卖出自动还债规则，支持币种只减仓状态。
- 当前币种的数量、成本、均价、账面市值和浮盈亏使用一致口径；全部 FX 汇总单独标识为账户快照。
- 报价统一为金圆券 / 外币，金额带币种；区分价格影响与报价变动容忍度，提供百分比档位和最低所得。
- 买入展示可用金圆券与比例快捷输入，明确余额、负债、冻结和读取失败等已知阻断原因。逐笔风控仍由服务端裁定。
- 成交回执使用交易响应中的实际投入、产出、手续费和成交均价；加载中、真实零值、失败、旧快照分别展示。

接口限制：当前成交响应不返回本笔实际还债金额。还债与现金净增加仅在下单预览中按最近账户快照估算；回执显示实际成交所得，并提示核对账户，不以账户前后差额冒充本笔还债。若后续补充精确还债回执，应提供仅本人可读、可幂等重放的成交结算明细，不能将个人负债信息加入公开成交接口。

## 第二轮：6–10（已实现，待用户体验反馈）

### 6. FX 工作台的移动端和桌面空间

- 手机提供固定买入 / 卖出入口，进入交易面板，减少穿过图表和长表单的滚动。
- 桌面考虑 FX 默认收起侧栏，使图表、下单和持仓更容易同屏查看。
- 验收：手机主操作容易找到，不遮挡输入和反馈；桌面图表宽度合理；保持键盘可用。
- 相关文件：`src/pages/Fx.vue`、`src/layouts/DefaultLayout.vue`；参考 LMSR 已有手机交易快捷入口。

### 7. 首页行情支持选择与判断

- 优先展示我的持仓，并能直接进入对应币种。
- 行情卡补充有明确时间窗口的涨跌幅、迷你走势、持仓标记和公开新闻时间。
- 调整现有最多六个品种、按状态和 ID 排序的展示策略，保留完整品种入口。
- 验收：指标有可靠数据来源；缺少历史基准时显示不可用，不伪造涨跌幅。
- 相关文件：`src/pages/home/FxHome.vue`、`src/components/home/FxOverview.vue`。

### 8. 行情、账户与报价的新鲜度

- 将小方块连接状态升级为可见的实时 / 重连中 / 数据可能过期提示。
- 明确行情、账户快照和报价各自更新时间，失联时给出恢复操作。
- 第一轮已补账户 / 持仓 / 成交快照时间，后续继续统一行情与报价状态。
- 验收：旧数据不冒充实时数据；失联、重连、刷新失败可区分。

### 9. 面向玩家的状态与新闻文案

- 清理页面中剩余的隐藏参数、管理员操作等实现说明。
- 新闻优先呈现事件内容、发布时间、相关币种；为空时只描述确知的状态。
- 第一轮已替换下单区的幂等键、409、min-out 文案；其余文案继续处理。
- 验收：用户能从提示知道发生了什么、下一步做什么，而无需理解接口实现。

### 10. FX 主次关系与视觉层级

- 统一功能名为“外汇交易”，保留“FX战士”作为品牌表达。
- 将含糊的“市场列表”明确为“预测市场”，降低次要玩法的导航权重。
- 保留黑白工业风，减轻内部边框与重复黑底标题，提高辅助文字可读性。
- 强调价格、到账金额、盈亏和主操作，避免所有区域同等抢眼。
- 验收：截图核对桌面和手机层级；不扩展为全站重构。

## 本轮交付与验证

- FX 和 LMSR 使用同一底部买卖入口与定位逻辑；交易面板可见 / 输入聚焦时收起，保留安全区和底部空间。
- 首页新增持仓直达、持有标记、SVG 走势与近似 24h 涨跌；仅使用窗口前已经收盘的 15 分钟 K 线作为基准，缺失不计算。
- FX 显示连接、重连、行情 / 账户 / 报价时间，报价超过 30 秒需重新获取再确认。修正重连首帧快照接收与切币旧响应回填。
- 清理实现术语，统一“外汇交易 / 预测市场”导航，收窄 FX 默认侧栏，调整移动端点击目标和内部视觉层级。
- 验证：105 项单测、类型检查与生产构建通过；未进行浏览器自动点击、填表或交易流程测试。全仓 lint 原有问题另行保留。
- 数据限制：无公开新闻历史接口，因此首页未增加新闻时间；FX 新闻明确只显示本次连接收到的事件。24h 涨跌基于 15 分钟采样，标注近似值。

## 后续约束

- 沿用 Vue 3 / TypeScript / 现有组件，不引入新 UI 框架或升级主版本。
- 金额保持十进制语义，公开行情不能包含隐藏事件参数或私人账户信息。
- 页面验证默认最多截图查看；未经用户明确要求，不做浏览器自动点击、填表或交互流程测试。
- LMSR 的金额下单与指标收敛仍为次要建议；本轮主要统一了移动交易入口，未扩展修改其交易算法。
