# 事件触发强平：后续范围归档

日期：2026-09-30。状态：延期草案，未批准实现，不是本期定时扫描的依赖。

用户选择先按 [统一贷款与固定强平 spec](2026-09-29-unified-credit-risk-design.md) 实现纯定时扫描，以减少开发量并使触发行为明确。本文件只保留未来讨论范围，不构成可直接执行的设计。

## 延期内容

- 玩家成交、FX 系统交易、新闻事件、计息、暂停恢复和注撤资触发风险标记。
- 持久化按品种/账户合并的 dirty 索引、风险 outbox、版本条件消费及崩溃恢复。
- 后台展开受影响用户、增量重估、实时强平续接与事件延迟指标。
- 事件工作队列与定时扫描去重、公平调度及必要的过载策略。

## 后续设计约束

仍须保留各产品真实清算算法、统一借贷规则、固定强平算法与动作幂等。交易内不得按持仓用户数同步扇出，不得通过全局经济锁牺牲独立市场并发，也不得只重验当前交易品种而忽略其他抵押品。

将来启动本项时，需重新确定触发范围、延迟目标、版本合并、重试和资源预算，并用 PostgreSQL 与定时扫描版本对照压测。此前提出的每秒处理、3 秒响应和自动停借均不是已确定要求。

本期不预建这些数据表、队列、触发钩子或调度器。现有行情 SSE 与成交审计仍正常保留；延期的是强平触发基础设施。
