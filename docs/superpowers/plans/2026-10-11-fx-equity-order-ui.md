# FX 本金倍数交易面板

**Goal:** 多空均用「本次开仓规模 / 当前账户本金」选规模，左侧只保留 K 线，右侧集中开仓、卖出多头与回补空头，持仓信息放 K 线上方账户栏。

**Architecture:** 沿用 Vue 3、Naive UI、现有页面状态与报价/成交 API。做多按总额和可用现金自动拆分，现金充足时走原现金买入，不足时走已实现的原子借款买入。做空仍以外币数量提交，金圆券规模只在用户调整时换算，不随行情自动改订单。

**Spec:** 本次对话已确认：本金取扣除债务、计入持仓盈亏的账户净值；非均匀滑条、快捷倍数和金额输入；明确本笔倍数而非全账户杠杆。本金使用现有清算净值，明细注明估值口径。后续确认保留四种操作 2×2 布局、本金与倍数合并、报价压缩，持仓纯信息显示在 K 线上方账户栏。

## 约束与审查重点

- 不新增接口、依赖或改变信贷规则；不使用 Superdesign，遵循前次已确认的正式 FX 页面路线。
- 金额保留十进制字符串，不将锁定现金作为可用现金。净值未知或不为正时禁用倍数选择，金额输入及减仓按已有规则处理。
- 滑条终点表示系统名义倍数档位，不声称为剩余可借额度；已有持仓、利息和费用仍由服务端逐笔风控检查。
- 净值或价格刷新不能静默放大已填写的开仓金额；修改金额、借款拆分或币种后旧报价立即失效。
- 不修改待确认订单身份、账号隔离、只减仓及 cover_all 含最新利息的规则。
- 浏览器只做只读截图，不自动点击、填表或交易。测试只覆盖实际资金拆分和规模换算风险，复用已有测试。
