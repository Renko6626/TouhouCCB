# 用户协议

## 1. 服务范围

TouhouCCB 是 LMSR 预测市场学习/娱乐站点，所有"金"币、市场、交易均为虚拟，
不代表任何法定货币或证券。

## 2. 禁止行为

**禁止使用任何形式的自动化脚本/机器人**访问本站 API，包括但不限于：
- 写脚本调用 /api/v1/market/{buy,sell,quote} 等端点
- 使用 headless browser / 自动化工具刷交易
- 多账号联合刷活动奖励
- 利用程序漏洞绕过 anti-bot 检测

违反者本站保留以下处理权（admin 自主决定）：
- 立即封号
- 没收账户内全部"金"币 + 持仓
- 取消活动奖励资格
- 公示用户名

## 3. 异常检测

本站运行行为分析系统，自动识别异常下单模式（高频/凌晨/规律性/毫秒级跟进
等）。识别到的可疑账户由 admin 人工 review 后处置。

## 4. 例外

站方运营的量化策略（如 quant trader）经 admin 明示加入白名单后不受
anti-bot 限制。这是站方运营行为不属于用户违规。

## 5. 修订

本协议可能修订；重大改动会站内公告。继续使用即视为接受新版。
