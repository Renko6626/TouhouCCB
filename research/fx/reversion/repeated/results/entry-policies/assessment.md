# 四组入场实验判断

40人、无外部冲击、三个预先固定种子81/82/83，各10000tick，共12条路径。原版seed81完整序列和摘要与前轮40人无冲击结果一致。所有组的每轮200外币、钱包、活动规则与退出规则相同，随机方向组也保留原版入场资格，只独立随机化方向。

按种子等权平均，每位短线已实现盈亏：原版−126.86金圆券，趋势权重四分之一−89.17，成交确认−33.92，同规则随机方向−152.35。三个种子中均保持这一盈亏顺序，四组仍全部亏损。每轮平均盈亏分别−1.76、−1.34、−0.82、−2.06，不能只用总亏损下降解释为少做交易。

成交确认的收益改善与减少趋势参与、交易组合改变相一致，但没有识别出有利趋势的证据。三个种子共3106个趋势主导合格候选，只通过87个（约2.8%，候选可包含同一账户在不同时刻的重复尝试），完成86轮，合计亏490.72，盈利轮次占比12.8%，每轮亏5.71。原版趋势主导完成973轮、每轮亏4.15。两组属于不同内生路径，不能把这两个子集的差简单当作门槛的纯因果影响。

因此，本轮支持降低趋势参与的积极性，尚不支持“多人持续买入后跟随就有盈利优势”。四分之一趋势权重方案较简单，三个种子均减少亏损；成交确认减亏更多，但主要阻止了约97%的合格趋势候选。其短线每户完成轮次从原版72.6降至41.3，中位持仓从12.06分钟延长到17.14分钟，常态30分钟市场波幅从1.58%降至1.39%，需要按游戏活跃度目标权衡。

同仓位、同退出的随机方向表现比原版更差。此前另一类随机机器人净值较高，不能作为“随机入场优于三因子”的公平策略比较。当前结果也没有单独识别退出规则、订单影响和其他参与者各自造成的损失；不同方案都改变了市场自身路径。

现有基线保持，未自动采用任何新方案。尚未验证80人、大事件或玩家介入，也没有继续调确认阈值或扫描参数。

验证：`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s research/fx/tests -v`，34项通过。逐tick核对12条路径的两币守恒、钱包非负、个人净值和成交计数；另独立核对10722个合格入场决策、3106次趋势确认、随机方向独立流及完成轮次盈亏。源码与旧结果哈希保持，见[validation.json](validation.json)。
