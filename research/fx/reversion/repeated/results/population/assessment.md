# 增员实验判断

本次增加账户并保持每户资金与同等热度下的到达频率，确实增强了日常波幅和大冲击后的回吐。40人的无冲击30分钟波幅中位数1.67%，冲击后10分钟平均回吐56.2%；80人分别为1.94%和86.8%。如果希望保留大事件带来的价格偏移，40人更适合作为下一轮应用候选。80人的平均回吐曲线仅1分20秒首次触及一半，明显快于此前约10分钟回吐一半的设想；这不是每次事件都在1分20秒完成，也不是持久半衰期。

增员同时增加总钱包资金和总到达规模。20/40/80人的初始资金相当于池市值10%/20%/40%，三类数量分别10/5/5、20/10/10、40/20/20。库存调节组人数与总调仓容量也随之增加，因此不能把回吐改善单独归因于更多账户或活动反馈。

代价是常态短滞后反转更强：lag1收益ACF为−0.033、−0.062、−0.081。超额峰度由4.87降至2.66、1.44；绝对收益ACF31–180只有0.00233、0.00342、0.00150，未显示波动聚集随人数单调增强。因此，游戏所需的活跃度与回归改善，并不等于各项真实市场统计特征一并改善。

每个人数一条无冲击和一条连续冲击路径；20人复用前轮高敏感版本，新增四条10000tick路径。单种子、前9次可观察事件，不能作为跨种子稳健性结论。原基线保持，未上线。

验证：`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s research/fx/tests -v`，31项通过。新增检查覆盖20人扩展模拟器逐字段/账本等价及80人分组、初始资金、到达规模和实际资产守恒。运行逐tick核对钱包非负、个人净值、两币守恒、首事件前因果前缀、事件幅度与终点事件；来源哈希见manifest.json。未做多种子、玩家介入或游戏性能验证。
