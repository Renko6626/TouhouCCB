# 20人低干预候选判断

在5秒tick、库存30分钟、热度tau45分钟、短线趋势权重¼的相同设置下，20人是比40人更轻的背景市场候选。三个种子81/82/83各10000tick，20人新跑常态/冲击六条，40人复用六条；池和每户资源不变。

20人常态每分钟实际成交7.85笔、绝对成交量695.5外币；40人15.86笔、1479.1外币，分别下降约50.5%和53.0%。总初始机器人资金相当于池市值的比例从20%降至10%。人数、总资金和总活动共同下降，不能单独归因于账户数量。

代价是常态30分钟波幅从1.92%降至1.57%，不再达到接近2%的水平；冲击后10分钟平均原始回吐从68.1%降至43.4%，事件后100秒平均成交从84.9笔降至50.7笔。20人背景仍有反向响应，但没有40人那么强的回吐能力，且不是所有事件都达到半幅。

短线常态持仓中位数从6.69分钟变为9.40分钟，仍处于用户希望的5～15分钟；冲击路径约4.97分钟。常态每户短线已实现盈亏−52.48金圆券（40人为−103.94），冲击路径−78.42（40人为−99.52）。未获得盈利优势，也不能把减亏全部归因于交易判断更准确。

建议按用户希望给玩家留空间的取向，优先将20人保留为低干预试用候选，40人保留为较强背景对照。不通过放大每户订单补偿减少的人数。本轮没有玩家，尚不能判定机器人是否挤占玩家机会或实际体验是否改善；30分钟波幅也不能预先假定会由玩家自然补足。

验证命令：`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s research/fx/tests -v`，37项通过。模拟逐tick核对两币守恒、非负钱包、个人净值及成交计数；正常/冲击的首事件前缀一致。新增人数通用指标在40人每个字段都与旧结果完全一致，20人的短线盈亏按5个账户归一化。原始模型和结果哈希保持。
