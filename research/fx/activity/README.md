# 活动反馈分支

**状态：活动反馈v1研究基线。** 机制探索阶段收尾，不继续为同一结论追加长模拟或调参。见[正式基线说明](BASELINE_V1.md)、[完整冻结清单](baseline-v1.json)及[封闭AMM上界补充](CLOSED_AMM_BOUNDS.md)。下一应用阶段的[玩家场景草案](PLAYER_SCENARIOS_PROPOSAL.md)待确认，尚未实现。

当前保留第一版模型，已完成[冻结版本稳健性验证](results/robustness/report.md)：五个新种子、每条50万tick、四格共20条路径。AMM反馈组在五个全程及15个连续时段上，101–300/301–1000的绝对及平方收益相关均为正；方向相关仍与固定率同量级。下一100/240块相关均值0.701/0.630，裁剪2.67%–2.89%。含预热强度峰值11.455、实际到达峰17，均为观测值而非上限；没有认证游戏运行阈值。原版代码、参数及首轮结果由[frozen-reference.json](frozen-reference.json)记录，哈希未变。

第一轮已实现并运行四格×三种子共12条路径，每条100000tick、预热5000。见[完整报告](results/reference/report.md)、[种子级指标](results/reference/metrics.csv)和[验证证据](results/reference/validation.json)。参数见[reference.json](configs/reference.json)，机制见[基线说明](BASELINE_V1.md)。

当前机制：过去带符号价格变化的累积，改变未来随机交易的到达强度，形成有限尺度的波动持续性；下一笔方向不由趋势信号决定。20账户共享公开历史形成的活动状态，不解释独立交易者的策略竞争涌现。

复用[common](../common/README.md)，不依赖归档M/R脚本。线性价格公式只用于线性参照；AMM价格只由真实成交改变。没有目标库存、M/R、成绩转换、补钱、重置持仓或强制成交。

首轮AMM反馈组在100/240tick下一块关系上三个种子均为正；301–1000段平方收益ACF均值0.00311，线性为0.00514。活动强度的经验高阶矩及ACF与平稳理论仍有差距，不能宣称宽尺度持续性或理论矩已经验证。后续稳健性验证支持同参数下的有限尺度重复性，没有消除这些理论边界。

实现保留在`model.py`、`run.py`和`report.py`；复算命令与全部统计口径在完整报告中。归档20N的三个种子与新固定率AMM在100001点、六个字段上完全一致。未调参或恢复旧M/R；未改线上市场。
