# 预热期 preset

`pve-mixed-20-warmup-v1` 用于玩家参与较稀疏的预热期。目标是完整往返40～60分钟、单边20～30分钟，典型上涨幅度比慢候选增加约50%。

- [完整参数与个人系数](CONFIG.json)
- [核心指标与逐种子数据](BASELINE_METRICS.json)
- [与活动当天版的比较和共同规则](../README.md)

四条24小时路径实测：成交 **5.24笔／分钟**、完整往返 **46.0分钟**、上涨 **24.6分钟**、涨幅 **2.69%**。

| 种子 | 成交／分钟 | 往返中位数 | 上涨中位时长 | 上涨中位幅度 |
|---|---:|---:|---:|---:|
| 20261029 | 5.32 | 48.3分钟 | 26.6分钟 | 2.63% |
| 20261030 | 5.19 | 49.8分钟 | 28.2分钟 | 2.62% |
| 20261031 | 5.20 | 42.2分钟 | 16.5分钟 | 2.45% |
| 20261102 | 5.25 | 43.8分钟 | 27.3分钟 | 3.08% |

前三个种子用于选择，20261102在选定后检查。主要波段采用1.5%反转门槛，固定1%门槛下仍有约23分钟的小一级往返。统计排除前30分钟，未结束轮次单列；不保证每段行情的时长与涨幅。

订单尝试约2.63%发生裁剪。四条路径的资产守恒、非负余额、有限数值及成交计数检查通过，已选种子的12小时前缀逐项一致。仅验证至24小时，一周连续运行、真人参与、正手续费和外部冲击尚未验证。

```bash
python -m research.fx.warmup.run --hours 24 --output output/fx-warmup-24h-final-20261016
python -m research.fx.warmup.plot --data output/fx-warmup-24h-final-20261016
```
