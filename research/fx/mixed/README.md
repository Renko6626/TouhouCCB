# 纯随机与个人三因子混合

沿用既有两套下单规则，在固定20户的有限钱包AMM内比较0/25/50/75/100%纯随机人数占比，逐一开关公共活动反馈。单个人口、三个行情种子、每条10万tick，共30路径；属于探索实验。

- [实验配置](config.json)
- [报告、指标口径与图表](results/exploration/report.md)
- [逐路径与分段原序列核对](results/exploration/audit.json)

75%纯随机＋25%个人三因子保留接近纯随机组的中尺度波动相关，方向收益ACF仍高于纯随机组；未确认最优比例或跨人口稳健性。原活动反馈v1与旧结果均保留。
