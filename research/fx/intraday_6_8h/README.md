# 活动当天 preset

`pve-mixed-20-intraday-6-8h-v2` 用于当天6～8小时模拟，arrivals＝0.6。用户已确认保留这一冻结版。

- [完整参数与个人系数](FROZEN_CONFIG.json)
- [核心指标与逐种子数据](BASELINE_METRICS.json)
- [与预热版的比较和共同规则](../README.md)

| 指标 | 6小时 | 8小时 |
|---|---:|---:|
| 场均成交总笔数 | 1905 | 2510 |
| 平均成交／分钟 | 5.29 | 5.23 |
| 典型上涨时长 | 3.9分钟 | 4.2分钟 |
| 典型上涨幅度 | 1.77% | 1.76% |
| 完整波段往返 | 9.1分钟 | 9.6分钟 |

三个已有探索种子，各运行8小时，6／7小时使用同路径前缀。波段统计排除前30分钟，采用1%反转门槛；指标为各路径中位数的平均。结束不强平，未结束轮次单列。既有长路径前缀逐项一致，资产守恒和余额检查通过。

复跑默认7小时；以下命令生成6／7／8小时指标：

```bash
python -m research.fx.intraday_6_8h.run --hours 8 --output output/fx-intraday-frozen-20261016
```

预热用途不修改这份参数。线上配置与活动开停时间不由模拟入口控制。
