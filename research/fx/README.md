# FX 机器人预设

生产默认采用[预热EMA10版](inventory_ema/SELECTED_CONFIG.json)，管理页可选择[活动当天冻结版](intraday_6_8h/FROZEN_CONFIG.json)。两套均为20户：10随机、3库存、3回归短线、4趋势短线；每5秒一个tick。填入预设后保存运行设置，新账户保持暂停；已有账户不自动改参。

| 项目 | 默认预热EMA10版 | 活动当天冻结版 |
|---|---|---|
| 库存参考 | 对数价格EMA，半衰期10分钟 | 75分钟滚动对数均值 |
| 完整往返 | 约47.6分钟 | 约9～10分钟 |
| 单边上涨 | 约21.5分钟 | 约4分钟 |
| 上涨幅度 | 约2.57% | 约1.8% |
| 每分钟成交 | 约5.30笔 | 约5.2笔 |

预热数据为4个种子的24小时路径，剔除开头30分钟，以1.5%反转识别波段；活动当天数据为原冻结实验，以1%反转识别。时长和涨幅为每种子中位数的等权平均，均为无玩家、无冲击、零费率模拟。默认算法不会自动改变池子、资金、费用、开市状态或运行时段。

[EMA实验、指标与复跑](inventory_ema/README.md)；[活动当天复跑与指标](intraday_6_8h/README.md)。原[滚动均值预热配置](warmup/CONFIG.json)及指标保留作基线。生产运行参数保存在backend/app/services/pve_fx/presets.py，时间统一用秒，不依赖研究目录。默认库存EMA只保留标量状态；价格队列仅供短线窗口及旧版滚动算法使用，默认最多600个价格。EMA与其他内存行情状态一样，进程重启后从当前价格重新初始化。
