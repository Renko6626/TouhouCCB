## 历史交接（2026-10-14，后续试验见上）

**当前状态：近期阈值持仓、慢调仓等尝试已经归档并停止，回到朴素的固定异质三因子模型。下一步先严肃研究 Lux–Marchesi，不自动继续旧网格，也不直接实现模仿或策略切换。** 旧脚本、报告和数据保留，不代表这些方向仍在推进。

### 我们要解决什么

这是一次趣味外汇模拟活动：约一周预热盘、6小时集中活动盘。预计参与者等效约50人，每人初始500本币，最高10倍杠杆。默认1外币=5本币，初始AMM池100万本币、20万外币；央行事件可注入本币或外币，单次冲击预计最多约10%。玩法背景见 [数值设计](../../docs/fx-gameplay-design.md)。

机器人提供日常行情波动，希望有趋势和反向交易的行为，但不希望形成真人难以抗衡的“市场主力”。研究并非追求现实FX很小的涨跌幅，也不要求真人常态依靠高杠杆才有体验。活动时间、池深、机器人规模的玩法校准，与长期统计特征复现是两件事，目前尚未完成它们之间的映射。

离线研究的目标是：用尽量简单、能解释的机器人，在AMM中内生生成行情，检查哪些真实市场特征能出现、靠什么出现。保持Python基础设施薄，复用生产Decimal AMM，不需要运行后端、数据库或线上机器人。优先没有持续外部价格锚的方式；用户此前明确希望除非走投无路，尽量避免人被其他人实时影响的群体模仿模型。现在研究Lux–Marchesi不等于已经批准其群体机制。

### 当前模型：新会话应从这里接续

唯一当前基线为 [configs/baseline.json](configs/baseline.json)，直接复制此前Q500混合组三个种子的配置，参数没有再调。

| 外部冲击 | 模拟器保留央行注资接口；基线及近期机制对照没有注资 |

令x=ln(P)，当前三因子信号为：

- 趋势T=(x_now−x_past)/L，即窗口平均每tick对数收益。
- 回归M=历史对数价格均值−当前对数价格。
- 预期差g=aT+bM+σɛ，ɛ为标准高斯；g是预期对数价格相对当前对数价格的差。

“回归主导账户”只表示其确定性权重配置；不能据标签断言实际信号由回归主导，需要测量各因子的实际标准差和相关性。近期均价不是独立基本价值。

所有账户每tick更新预期，再按到达交易，模拟器随机排列账户并逐笔成交。账户有很大的双币记账储备，省略借贷开空流程；有效净外币仓位仍受±500约束。“一单200本币”是旧固定规模订单的设置；当前有界目标仓位模式的订单由仓位差决定，配置里的order_size=200不限制它每单为200。每人500外币容量在初价时约为2500本币名义头寸，不能把它当作真人500本币初始资金。

### 指标：分别判断，不打一个“复现成功”总分

收益r_t=ln(P_t/P_{t−1})，波动代理主要为|r|，也检查r²。tick尚未映射现实分钟，不能直接和日线或逐笔成交论文比较。

| 目标特征 | 计算与判读 | 当前证据 |
| --- | --- | --- |
| 收益方向相关较弱 | 带符号收益ACF及不同延迟 | 有些组ACF(1)接近零，但并非无其他尺度结构 |
| 非高斯尖峰与较厚尾部 | 分布、超额峰度，区分零/非零收益及池深影响 | 多组出现；不能据峰度认定幂律 |
| 聚合后趋近高斯 | 非重叠多tick收益聚合，比较分布与峰度 | 部分参数有这种趋势；不是完整正态性证明 |
| 波动聚集 | 绝对收益、平方收益的持续正相关，结合波动和成交路径 | 部分组有短期/有限尺度相关，机制尚需解释 |
| 波动长期记忆 | ACF衰减、完整DFA1/2曲线、修正R/S、打乱对照、多个尺度与种子 | 没有稳定确认；周期、库存回复、漂移和阶段切换会干扰 |
| 稳定幂律尾部 | 尾部阈值/跨度/样本数敏感性、替代分布、拟合优度与跨种子重复 | 没有稳定确认；厚尾不等于纯Pareto |

用户特别要求严肃核对算法与“是否符合”的判定。已有独立尾部和记忆审查、相应修复及合成控制；不要绕过这些口径。修正R/S大块斜率和论文beta_n不能直接称Hurst。DFA报告预声明的32–256、512–8192、2048–8192 tick区间；曲线存在弯折/平台时，不能压缩成一个H。理想目标是收益H接近0.5、波动H明显高于0.5，但仅两个拟合数值好看不构成成功。

筛查的bootstrap=0只提供描述性尾部拟合。连续iid Pareto被拒绝不等于所有厚尾都不存在，未拒绝也不等于复现。归一化波动使用r乘当时本币池深/初始本币池深，是辅助诊断，不是完全消除所有流动性影响。方法入口见 [顶层指标说明](../../MARKET_STATISTICS.md)、[尾部审查](audit-tail.md)、[记忆审查](audit-memory.md)、[DFA说明](hurst-findings.md)。

### 阶段困难：事实与推测分开

**已知结构约束：**忽略手续费、量化和注资，令机器人相对初始外币余额的净仓位为q_i，则F_pool=F_0−Σq_i，P=k/F_pool²。固定有限总容量且ΣQ_i<F_0，价格有界，累计收益不能在无限长尺度保持随机游走式扩散。当前总容量20×500=10000外币，仅为池外币的5%；理想价格范围约为初价的0.907–1.108倍。有限尺度仍可能有聚集、截断厚尾或近似扩散，不能用有界性否定全部市场特征。手续费转出池会改变这条理想关系并造成慢漂移；不能把费耗漂移算作复现收益扩散。

**已知实验现象：**实际仓位在旧Q500混合组里远未普遍撞上500上限，单人峰值约108–119、总净仓位峰值约497–551。早期收益DFA平台不能简单归因为“撞到上限”。慢调仓确实推迟平台，却没有同时保留理想波动持续性。

**尚未证明的解释：**目标信号变弱时，仓位向零回复；新噪声每tick更新，机器人反复向新目标调仓，可能带来较快的库存回复。固定弱非线性群体可能近似一个平均响应；共同窗口和延迟反馈可能产生周期。这些都不能直接升级成当前失败的唯一原因。改变窗口、噪声、规模、调仓速度时，常同时改变实际信号增益或成交量；需避免把更大波动当作更逼真的统计结构。

**研究层面的困难：**模型必须足够薄才能识别主要机制，但真实统计特征可能依赖多个耦合反馈。尚未找到已核查、与我们同样封闭的恒定乘积池和固定异质金融账户、可靠复现全部六项特征的简单现成模型。AMM实证、真实订单重放、外部套利模型的成功不能直接证明我们的内生生成机制成功。详见 [纯AMM文献](closed-amm-literature.md)。

### 文献理解与下一步边界

- **Chiarella–Iori–Perelló：**有异质预期、期限、波动率风险调节、外部基本价值、预算约束与限价单执行。它没有明确的F–J双阈值持有机制，预测期限/订单有效期不能当作强制持仓期；目标持仓重新计算与我们的机制有相似之处。多个因素并存，不容易识别主要贡献。
- **Farmer–Joshi：**仓位变化产生订单，另有入场/退出阈值及持仓状态；无需实时模仿也能出现厚尾和波动相关。但它有价值锚与不同的价格冲击规则，不能据此保证AMM适配有效。我们已做阈值试验，当前停止这条方向。
- **Lux–Marchesi：**原文明确存在策略组成变化、多数情绪和群体规模影响。1999示例报告收益H约0.48、绝对收益H约0.85；2000分析将波动爆发与技术派占比越过稳定性边界联系起来，再由价值偏离反馈恢复稳定。1999基本价值随机变化；2000也有固定基本价值实验，但外部锚仍在。详见 [原文研究笔记](lux-marchesi-notes.md)。

下一步先理解Lux–Marchesi的“策略组成→反馈强度→暂时失稳→恢复”链条，并明确原版模仿、收益驱动转换、基本价值和交易执行分别起什么作用。若仅借鉴个人行情/策略成绩驱动的缓慢适应，应标为自己的适配，不能继承原版成功结论。原模型持续超额需求与当前目标仓位饱和后的订单衰减也不同；动态组成不能自动解除AMM净库存约束。

本轮没有批准实现Lux–Marchesi，没有批准引入模仿或新的价格锚。新会话不要自动重启旧实验或把待讨论机制一次全加进去。先展示路线和取舍，遵循项目AGENTS.md，重大模型选择需确认。

## 六个行情统计特征：历史单轮示例

当前优先研究下面六项，不把它们当作每个市场、每个时间尺度都必须满足的定律。厚尾、稳定幂律、波动聚集和长期记忆分别判断，不能互相替代。

| 特征 | 描述与检查 | 历史单轮结果（b=1、sigma=0.001） |
| --- | --- | --- |
| 收益方向相关较弱 | 带符号收益ACF应较快衰减；弱相关不等于独立 | ACF(1)=0.026，仍有短期结构，方向上接近 |
| 非高斯尖峰与较厚尾部 | 分布、超额峰度、与同尺度高斯比较；需检查零收益与池深影响 | 超额峰度3.31；仅非零收益约0.99，部分相似 |
| 聚合后趋近高斯 | 比较不同非重叠时间块的收益分布、峰度；不能仅靠峰度证明正态 | 1/5/30/240tick峰度约3.31/0.81/0.16/-0.06，峰度层面相似 |
| 波动聚集 | 绝对或平方收益有持续正相关；大波动后较容易继续大波动 | 绝对收益ACF(1)约-0.0009，本轮不明显 |
| 波动长期记忆 | 检查绝对收益相关的跨尺度衰减、修正R/S与打乱对照；排除周期与慢漂移 | q20大块斜率0.494，位于打乱范围，本轮无支持证据 |
| 稳定幂律尾部 | 阈值敏感性、足够尾部跨度、替代分布、拟合优度及跨种子重复；与一般厚尾不同 | 拟合跨度约0.3数量级，连续iid Pareto检验拒绝，尚无稳定证据 |

这是单轮30万tick、seed21的结果，详见 [增强回归与降低噪声对照](figures/position-strong-reversion-seed21/README.md)。整个网格仍有有限尺度持续性候选，见 [网格报告](position-grid-findings.md)，不能把这条弱反馈序列的缺失推广到所有参数。tick尚未映射现实时间。

当前基线分为两组固定因子权重，历史窗口、到达率及调仓比例相同，仍可能倾向单一反馈尺度和集体周期。异质期限可能带来更多时间尺度，但它既不是上述特征的已证明必要条件，也不保证这些特征涌现；需要控制实验。这仍是待检验的解释。

真实市场背景参见 [现代股票统计特征研究](https://arxiv.org/html/2311.07738v2)；其研究支持多项典型特征，也说明它们不能作为无条件通用清单。

## 归档与历史实验

已归档的 [F–J式阈值持仓对照](threshold-findings.md)比较连续目标、统一阈值和异质阈值，共21条正式运行。高统一阈值产生长静默与活跃阶段切换，全程相关不能直接解释为稳定长记忆；异质组未同样改善中期持续性。

已归档的 [封闭AMM时间尺度对照](closed-timescales-findings.md)结合两份独立调研，追加9条无外部价格、无模仿运行。慢调仓推迟收益平台，却压弱波动持续性；尚未得到稳定的Hurst组合。相关证据见 [纯AMM文献](closed-amm-literature.md) 与 [库存回复核对](closed-amm-dynamics-audit.md)。

Q500混合组的 [Hurst/DFA检查](hurst-findings.md)显示：收益在大尺度出现饱和，不能认为H≈0.5；绝对收益有较高有限尺度斜率，但尺度与去趋势敏感性尚未支持稳定长记忆。

低噪声混合组将每人Q提高到500的三个种子，出现更明显的有限尺度波动持续性，详见 [账户组合实验的Q500追加对照](factor-mix-findings.md)。这仍是10万tick筛查，尚未确认长记忆或稳定幂律。

最新的 [趋势/回归账户组合实验](factor-mix-findings.md)完成四组×三个种子：两种账户各半与全员平均系数组表现接近，未出现明显的新波动聚集。`factor_mix`按等人数分配固定(a,b)，并记录分组因子量级。

最新的 [异质窗口对照](window-mix-findings.md)完成五组×三个种子：本轮混合窗口未产生明显波动聚集或长期记忆。配置中的`window_mix`按等人数固定分配趋势和回归窗口，空值保留同质配置。

最新的有界目标持仓扫描见 [网格结果与确认实验](position-grid-findings.md)：174条运行、2100万tick，含容量、速度、窗口及人数对照。复算配置为`configs/position-*-grid.json`和`position-grid-confirmation.json`；汇总入口为`position_grid_report.py`。

```bash
# 三因子系数 × 典型窗口，全因子网格，每条10万tick
python -m research.fx.experiments --config research/fx/configs/factor-grid.json --output research/fx/results/factor-grid --workers 8

# 人数、单笔金额、到达率对照，每组3个seed，每条10万tick
python -m research.fx.experiments --config research/fx/configs/flow-grid.json --output research/fx/results/flow-grid --workers 4
```

配置 JSON 包含 `defaults`、`grid`、`cases`、`seeds`。`grid` 是全因子笛卡尔积；`cases` 追加显式覆盖；相同配置去重。`window` 同时设置趋势与均价窗口，也可分别设置 `trend_window` / `mean_window`。系数、人数、每机器人到达率、单笔本币等值规模、ticks、burn_in 都是配置参数，入口不固定两档回归系数。

每组按配置哈希分目录，`result.json` 记录参数、代码哈希、状态、实际成交流量和因子量级；`series.npz` 保存完整价格、真实本币池深、每tick成交数/买入数/成交本币量；`diagnostics.json` 保存统计结果。总目录的 `manifest.json` 定义计划，`summary.json` 汇总已完成结果，失败组明确记录错误。只有参数、代码哈希与分析设置相同时跳过已完成组。

默认 `--bootstrap 0` 是描述性筛查，不提供Pareto拟合优度结论。确认阶段使用 `--bootstrap 200 --shuffles 10`；独立重复种子和更长运行用于确认，不能将网格中最大指标当作规律。新分析明确区分连续iid尾部检验与厚尾现象，不给整体“符合市场”的自动二元判定。

每tick更新所有机器人并随机排列顺序，逐笔成交。连续指数时钟的到达收集到整数tick，一个tick可有零或多单；同机器人同tick的多单共享这次预期。固定名义卖单按当时观察价换成外币、六位向下量化。tick不自动代表现实分钟；与论文交易事件时钟比较时需要说明口径。

## 三因子预期

`x=ln(P)`，`T=(x_now-x_past)/L`，`M=mean(x_past)-x_now`，`epsilon~N(0,1)`。

`gap=a*T+b*M+sigma*epsilon`，`target=P*exp(gap)`，`p_buy=sigmoid(sensitivity*gap)`。

固定订单模式下，主观目标价改变方向概率，订单规模和到达率不随信号变化。有界持仓模式下，预期差决定目标净持仓，订单规模取决于目标与实际持仓之差；到达率仍固定。近期均价没有固定长期价值锚点。趋势/回归历史不足完整窗口时置零，随机预期仍抽取；与原论文的外生基本价值、CARA目标持仓、异质期限及订单簿机制不同。
