## 研究问题与实验分组

本报告可直接作为外部模型的审阅材料；下面给出实际运行规则和计算口径，不依赖读者打开配置或源码。研究问题是：在封闭、有限资金、真实恒定乘积AMM中，个人缓慢追逐较有效的趋势/回归规则，能否比固定组成和无成绩偏好的随机转换产生更持久的波动状态？本轮没有外部基本价值、外部行情、玩家订单、资产注入、做空、杠杆、羊群输入或波动驱动参与率。

| 组别与输出名 | 初始人数M/R/N | 可转换账户 | 重选规则 | 作用 |
|---|---|---|---|---|
| 固定A，`fixed` | 8/8/4 | 8人仅作影子成绩记录，不采用重选 | 类型始终固定 | 基线及beta定标 |

## 实际模型与每tick时序

### 公开信息与信号

定义P_t为tick t全部成交之后的池中边际价，p_t=ln(P_t)，P_0为初价。tick t的所有人只读取P_(t−1)及更早价格，使用同一公开收盘历史；执行器会读取本tick每笔成交前的最新池储备，但不会因此更新个人信号。

每个非噪声账户每tick更新一次个人对数价EMA，并同时计算两个候选规则：

```text
v_i(t−1) = (1−alpha)*v_i(t−2) + alpha*p_(t−1), alpha=2/31
e_i^M(t) = p_(t−1) − p_max(0,t−1−30)
e_i^R(t) = v_i(t−1) − p_(t−1)
```

启动不足30tick时用最早P0补足趋势比较端点；不跳过启动阶段交易。M/R没有独立基本价值锚，R的参考完全来自市场自身历史。若解释为预期价，P_hat=P_(t−1)*exp(e)：正信号为预期高于当前公开价，负信号为低于它。实际交易规则使用信号和持仓状态，不把池价直接推到P_hat。

### 滞回、目标库存与真实订单

每个M/R账户实际状态z∈{−1,0,+1}，分别表示低配、基准、高配，不表示空头/空仓/多头。每次交易到达按以下**优先顺序**更新，比较符均严格：

```text
若 e > 0.0005：z := +1
否则若 e < −0.0005：z := −1
否则若旧z=+1且e < 0.00025：z := 0
否则若旧z=−1且e > −0.00025：z := 0
否则保持旧z
h_target = 1000 + 500*z
q_want = 0.2*(h_target − h_actual)
```

例如强看涨时目标1500外币，从初始1000库存出发第一单想买100外币；后续在价格信号仍允许的情况下逐步靠近固定数量目标。回到z=0是回基准1000，**不是清空钱包**；z=−1目标仍500，没有借币卖空。阈值恰好相等时按上面严格比较决定，可能保持原状态。

转换改变当前使用的M/R规则，不自动重置z、不强制清仓，也不立即成交；到下次真实到达时，用新规则信号处理旧z。个人持仓期间允许重选。本轮采用稿件的“固定目标数量＋分步靠近”，没有沿用旧“一次建仓后固定这笔数量，直到完整退出”的执行语义。

N每次到达直接抽取q_want=40*epsilon；不维护随机目标库存，也不乘eta，不存在M/R阈值。无库存约束时噪声库存会随随机订单累积；实际始终受有限钱包裁剪。

### AMM执行与守恒

执行前记池储备G、F，理想无量化的零费率恒定乘积k=GF。想买q外币时所需金币为G*q/(F−q)；想卖q外币时得到金币为G*q/(F+q)。所有成交通过生产报价器计算，使用每笔执行前的最新G、F和账户余额。实际流程为：

1. 将外币数量裁为min(|q_want|,0.005F)，向下量化6位。
2. 卖单再裁为不超过当前账户外币余额；买单先计算买足该外币量的所需金币，若现金不足，改用全部当前现金买入可买到的外币量。
3. 金币输入要求向上量化、币/金币输出向下量化；输出舍入为零时不成交。买卖均禁止负余额。
4. 成交后更新账户和池储备；价格只能由这些真实成交改变。

理想公式k不变，但6位保守舍入可以令实际k微增，零手续费不意味着数值k每笔严格相等。严格校验的是系统两种资产分别守恒和钱包非负，不强行断言量化后的k恒等。无流动性添加、销毁或外部注入。

### 影子策略、评分与重选

全部16个非噪声账户都运行两个影子M/R；只有固定的8个有资格账户可能采用转换。影子没有真实钱包，不调用第二套AMM，不受真实现金/币余额裁剪。影子状态用同样信号与滞回，每次该账户实际到达时依次更新：

```text
z_shadow^s := hysteresis(z_shadow^s, e^s)
u_shadow^s := u_shadow^s + 0.2*(z_shadow^s − u_shadow^s), s∈{M,R}
```

u是相对于基准库存的标准化主动敞口（主动500外币对应|u|=1），两规则风险规模相同。它是按到达逐步调整的虚拟敞口，不是每tick直接取信号正负号。评分不包含基准1000外币的共同持仓收益。

tick t开始，实际代码先用tick t−1结束时保存的影子敞口记刚观察到的收益，再产生本tick信号与订单：

```text
r_(t−1) = ln(P_(t−1)/P_(t−2))   # t=1时设0
pi_i^s(t) = u_i^s[t−1结束] * r_(t−1)
U_i^s(t) = (1−gamma_i)*U_i^s(t−1) + gamma_i*pi_i^s(t)
Pr(M | 有重选机会) = sigmoid(beta*(U_i^M(t) − U_i^R(t)))
```

**评分时点偏差：**u[t−1结束]可能已在tick t−1的到达过程中调整；r_(t−1)也包含这个tick的成交价格变化。因此代码将区间结束时的影子敞口应用于该区间全部收益，没有严格实现“收益区间开始前已有敞口×之后收益”。例如当期从u=0新建到u=0.2时，下一tick开始会记0.2*r，而非期初0*r；退出当期也会改变整段计分。它没有读取未来价格或使用tick t新信号，但有区间内敞口归属偏差，并可能将自身新成交影响计入新敞口成绩。

若按纯收盘持仓近似，要单独保存u[t−2结束]用于r_(t−1)，或明确规定交易/持有收益的分阶段时序。这里仅指出待核验问题，没有选择修正方案、改变算法或重跑。本轮B结论是这个实际实现的观测，不宜直接视为严格滞后评分机制的检验。此前报告与计划中的“旧敞口、避免前视”描述不够精确，以本节实际时序为准。

成绩不扣手续费或滑点，不算可兑现净利润。重选不要求得分领先者必胜；随机组beta=0，B使用冻结beta。同一规则被再次选中算一次机会、不算一次真实转换。8人的期望重选机会合计约800次/10万tick，实际约796–823；真实转换通常更少。

beta定标对固定A三个种子、8个有资格账户、tick5001–100000的个人成绩差DeltaU逐项平方后合并：

```text
RMS = sqrt(sum_seed sum_tick sum_eligible (DeltaU_i(t))^2 / (3*95000*8))
beta = 1/RMS = 47443.707294452535
```

它不是先平均个人成绩差再取RMS，也不是收益标准差；gamma每tick平滑，即使账户没有交易到达也更新成绩。gamma仅影响成绩记忆，行情EMA与H本轮对所有人相同。

### 一步执行顺序与配对方式

每tick依次：①用上一收盘收益更新影子成绩；②更新EMA和M/R信号；③有资格者抽取重选机会及新类型；④收集每人的Poisson到达，打乱事件列表；⑤逐笔更新实际/影子状态并用即时钱包/池执行；⑥保存当前收盘价、资产、类型人数等。重选在交易到达之前，即使本tick没有交易到达也可改变类型。

每账户到达计数预先生成，噪声需求、类型选择、执行顺序用分离随机源。A/随机/B在同种子下到达列表、噪声原始需求和执行事件顺序一致，成交与价格可以不同。实际校验保存序列的到达总数与噪声未裁剪净需求逐点相等；这不意味着已成交订单数量、成交量或钱包余额相等。

## 指标定义、样本和汇总口径

### 样本边界

每条保存100001个价格P0…P100000，定义r_t=ln(P_t/P_(t−1))，共100000个tick收益。主收益指标剔除最初5000个收益，使用r5001…r100000，共N=95000；预热阶段照常交易、记分和转换，仅不进入这些主统计。

### 收益分布与聚合

| 指标 | 定义及口径 |
|---|---|
| 收益/标准差 | 自然对数收益r；样本标准差sqrt(sum(r−mean(r))²/(N−1))，`ddof=1` |
| 零收益比例 | 原始双精度r恰好等于0的个数/N；不是按“很小”阈值裁成零，也不等同于无到达或无成交比例 |
| 非零收益统计 | 仅对r!=0的子样本计算分布；ACF/DFA仍保留所有零收益，不将时间轴压缩为成交时钟 |
| 超额峰度 | SciPy `kurtosis(..., fisher=True, bias=False)`；高斯基准0，普通峰度=超额峰度+3；不是原始四阶矩 |
| 偏度 | SciPy `skew(..., bias=False)`，采用有限样本修正 |
| 聚合收益 | 从r5001开始按w=1/5/30/60/240/1000连续、不重叠分块，每块相加，末尾不足w的收益舍弃；不使用滚动重叠窗口、不对收益取绝对值后相加 |

若m_j=(1/N)sum(x−mean(x))^j、g2=m4/m2²−3，则报告的有限样本修正超额峰度为 `(N−1)/((N−2)(N−3))*((N+1)*g2+6)`（有效样本N>3且方差非零）。每种聚合后的样本数依次95000、19000、3166、1583、395、95，再对各自样本做相同分布统计。大窗口尾部估计的样本量明显更少。

### 自相关ACF与区间均值

对x=r、|r|、r²分别计算；三者对应方向收益、绝对收益波动代理和平方收益波动代理，不是不同持有期的收益。使用整个分析样本的同一均值，计算：

```text
ACF_x(k) = sum_(j=1)^(N−k) [(x_j−mean(x))*(x_(j+k)−mean(x))]
           / sum_(j=1)^N (x_j−mean(x))^2
```

实现用FFT，最大k=5000；没有再除N−k或乘N/(N−k)做无偏修正。ACF(0)=1；常数序列返回NaN，避免伪造相关性。报告“101–300均值”就是200个滞后ACF值的算术平均，端点都包含，不是该区间的一次收益聚合。记录的滞后段为1、2–10、11–30、31–100、101–300、301–1000、1001–5000。

分段诊断从r5001起取9个完整10000tick块，范围5001–15000，依次到85001–95000，舍弃末尾95001–100000的5000收益。每块独立去均值计算ACF到1000，并记录101–1000的900个滞后均值、收益标准差与超额峰度。分段没有重叠；也没有把块当作已经证明独立的重复实验。

### DFA与图中的波动代理

DFA输入分别为95000个r和|r|。先去全样本均值，形成累计剖面Y(j)=sum_(l≤j)(x_l−mean(x))；对尺度s分前向/后向块，每块拟合一阶（DFA1）或二阶（DFA2）多项式，再对全部块和块内残差平方取平均、开方得F(s)。前后分块可能重叠，不算独立样本；每方向不足8块的尺度不用。

实际尺度列表为 `16,24,32,48,64,96,128,192,256,384,512,768,1024,1536,2048,3072,4096,6144,8192`。固定拟合区间32–256、512–8192、2048–8192，端点包含，至少3个有效尺度点；在ln(s)与ln(F(s))上做普通最小二乘斜率拟合，同时保存R²。本轮95000收益在最大8192尺度仍每方向有11块。主表报告512–8192区间的DFA1斜率，DFA2在每条result.json中另存。

这里斜率是指定有限区间的经验量。接近0.5不单独证明扩散；对|r|大于0.5也不单独证明长期记忆。没有DFA置信区间、洗牌显著性或拟合区间优化。

价格路径图中的“100-tick return standard deviation”采用全程100000收益，按100tick不重叠分1000块，每块计算总体标准差（`ddof=0`），横坐标放在块中心；它与分布表的`ddof=1`样本标准差不同。该图不剔除预热，也不是滚动波动或真实时间年化波动。

| `trades` | 本tick成功真实成交笔数，零输出/无余额跳过不计；总值为完整实验求和 |
| `gold_volume` | 买单金币输入＋卖单金币输出的正数总和，单位金币；无净额抵销，不是外币成交量或利润 |
| `switches` | 8个有资格账户的新类型与旧类型不同的累计次数；不是每次机会都算转换，也不是z的变化次数 |
| `choice_opportunities` | 低频重选Bernoulli成功次数，同规则再次被选中也计入 |
| `trend_count` | 当前使用M的账户数；按重选之后、tick成交结束记录，已换M但暂未成交也计入 |
| `trend_equity_fraction` | M账户按当前边际价估值的总资产/全部账户总资产，E_i=g_i+P_t*h_i；包含基准资产和噪声账户分母，不是主动幅度占比、成交贡献或可清仓资产价值 |
| `score_difference` | 8个固定资格账户的UM−UR算术平均；不是beta定标使用的个人差平方RMS |
| `range_pct` | 100*(max_(0…100000)P/min_(0…100000)P−1)；不是最高最低差除初价，也不是最大回撤 |
| `budget_clipped_orders` | 成功成交且实际外币绝对变化＋0.000002小于执行前min(|q_want|,0.005F)的笔数；用2e−6容忍量化误差，零余额直接跳过不计，因此不是所有资金约束事件数 |
| `cash_saturated`/`foreign_saturated` | 本tick收盘余额分别小于1e−6金币/外币的账户人数；比较严格，不是持仓达到目标或策略饱和 |
| 饱和tick比例 | 预热后95000个tick中，上述对应人数>0的tick数/95000，表示至少一人接近空余额 |
| 期末资产 | 现金＋期末池中边际价×外币库存；未模拟清仓、不扣清仓滑点，不自动等于实现收益 |

B每条实际转换317–354次，趋势人数在种子41/42/43分别为4–11、4–10、4–11；固定A始终8人。类型确实变化，不是转换开关没有生效。随机转换的短程波动相关性反而更大，本轮没有成绩选择优于随机选择的证据。

三个策略组的相关性主要仍集中在约30tick以内。每10000tick完整区间另保存了分段统计：B的101–1000tick均值在各段约−0.00123至0.00175，未出现稳定正相关平台。本轮没有做置信区间或正式长记忆检验，这些数值只能支持“未见明显改善”，不能证明所有参数下B都无效。

约36.74%的零收益与合计到达强度20×0.05=1时无到达概率exp(−1)约36.79%一致。剔除零收益后峰度大幅下降，而且纯噪声组也有约3.10的全样本超额峰度。因此仅凭全样本峰度不能认定形成了市场式厚尾；本轮没有进行幂律拟合/检验。

转换对部分聚合尺度的尾部有影响：240tick非重叠收益的平均超额峰度，A为−0.36、随机转换为1.96、B为3.94；B三个种子分别为4.03、1.67、6.12，差异较大。B在1000tick尺度降到平均0.33。这个变化应保留，不能把“未形成长记忆”写成“转换完全没有效果”；聚合尾部变化与长程波动相关性是两个不同观测。每条240tick聚合仅395个样本，1000tick仅95个，尾部估计不稳定，尚不能推广。

价格方向收益的长尺度DFA斜率仍低，成绩转换未使其接近扩散尺度。封闭资金和回归反馈是需要继续区分的机制；不能仅凭斜率就断言是哪一个导致。

三个策略组每条约243–305笔订单受到钱包裁剪，主要噪声账户会碰到余额边界；纯噪声组约1215–1355笔。统计中“现金/外币饱和tick比例”指任何一个账户接近空余额，不是全部账户耗尽。纯噪声组有20个噪声账户，而A/B只有4个，其订单源强度不同；此组是独立订单源参照，不是仅关闭反馈的严格控制。
