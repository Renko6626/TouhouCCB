## 先固定比较，再看结果

三组各跑种子81/82/83的常态与原有双向冲击，共18条、每条10000tick（约13小时53分钟）。全程20户、5秒tick，每户5000金圆券和1000外币；10随机户、5短线户完全沿用冻结规则，仅替换中间5个库存户。共享热度、钱包约束、最大池成交比例、预算买入口径和生产AMM报价均保留。不同策略会改变价格和热度，因此同种子后续到达数也可能不同，不是固定行情的配对回放。

三组共用净库存目标上限±500外币、每次向目标调整50%。不扫参，不挑选最好种子，不在看到结果后调整候选。零手续费，与冻结研究相同。

### 原库存

原冻结模型：过去360个对数收盘价的均值作为参考，目标为 `500*tanh(100*(参考−上一收盘对数价))`。原始模拟器独立载入；六条基线轨迹与此前 `profit_trail04` 文件逐字段精确比较。

### 中位数库存

借鉴 `quant/thccb_quant/strategy/volharvest.py` 的鲁棒中心、MAD、不交易信号区间和平滑目标持仓。FX价格没有0–1概率边界，用对数价格替代logit；观察窗口沿用30分钟的物理时间，不使用成交事件窗口。

- 中心为过去最多360个对数收盘价的中位数。
- `scale=max(1.4826*MAD,0.001)`；尺度下限为0.1%对数价格。
- 偏离中心超过 `2*scale` 后，超出部分反向进入tanh，目标最大±500；区间内目标为初始库存。
- 所以已有偏仓在区间内仍可能被调回，不表示所有交易被禁止。尺度下限及以完整scale作门槛是本次适配选择，原quant按MAD计算门槛且另有低MAD跳过规则。
- 不移植底仓bootstrap、趋势保护或原quant成交驱动规则。本实验每户已分配初始外币；不是完整移植volharvest。

### 信念混编

借鉴后端 `BelieverTemplate` 的主观信念、长期锚点、从众、观点冲击，以及信念与动量加权。五户分别为看多铁杆、看空铁杆、追涨、波段、抄底；不包含需要独立净流量输入的跟风羊。

主观信念改用对数汇率。铁杆初始锚点分别比开场价高/低1.5%，追涨/波段为±0.3%，抄底为0；长期锚点只是模拟人物立场，不是外币基本价值。沿用LMSR的从众系数、短线权重、动量系数和观点冲击概率；冲击幅度另定为最多±0.2%对数价。每次到达时信念向现价和锚点调整，短线趋势是最近30tick的端点对数价差。FX中不再做概率归一化。

信号按1%尺度映射到±500目标；绝对信号不足0.1%时目标回到初始库存。保留库存户的50%调整与真实预算买入。这与原散户的按现金下注、弱信号跳过、概率止盈止损不同：这里只测试信念产生的目标库存，不能据此判定完整believer策略的盈亏。5个原短线户继续按冻结方案退出，没有被这些候选替换。

本研究没有真人成交，未启用“持续多人真人买盘使长期锚点改信”的机制，没有运营风向注入。初始锚点不会机械重置，但可能受各户私有随机观点冲击改变。

## 时间、资金及比较口径

每tick观察截止上一tick的收盘价，再执行本tick事件；候选逐次读取真实钱包，成交使用当时最新池储备。通过独立加载现有模拟器替换局部回调，不修改现有源文件，不覆盖冻结结果。原模拟器的 `slow_reference`/`inventory_target` 诊断仍描述旧均值规则；候选实际中心、信念、目标以各路径 `inventory.jsonl` 为准。

候选收益使用同一路径“保持最初5000金币+1000外币不交易”的期末市值作对照，包含未实现损益；这不是已实现盈利，也不是跨策略固定价格的收益比较。短线户另报已实现盈亏。冲击后回吐沿用原研究口径，终点冲击无后续不计入，多个事件不当作独立种子。

检查包括两币守恒、钱包非负、净值与真实钱包一致、逐人及全体成交计数、候选成交钱包变化、目标上限、完整历史文件哈希，以及同策略同种子常态/冲击首事件前轨迹完全一致。未添加永久测试，另运行受影响的已有研究检查。

局限：三个已用过的种子，只能形成探索线索；尚无真人、正手续费、持续单边趋势、24小时运行或线上性能验证。不以候选能赚钱作为唯一优先级，也不将波幅增加直接等同于玩家体验改善。
