# 6小时与24小时局长探索

用户给定1tick＝10秒，一局6～24小时，并同意尝试调整节奏。沿用Python与现有真实AMM、有限钱包、异质三因子入场及移动退出模拟器；只改变既有参数，不新增机制。

运行前冻结[五组参数](config.json)：原参数、全部退出阈值减半、四分之一、仅热度记忆缩至180tick（30分钟）、阈值减半并缩短记忆。每笔100外币、入场门槛、账户到达规则、反馈系数0.25、钱包和池深度均保持。热度记忆的30分钟指z的指数衰减参数，不保证实际强度ACF或退出时间也为30分钟；相同收益冲击在较短记忆下对z的即时影响会更大。

仅比较原移动退出版；固定退出的既有结果保留，不扩大网格。20行为与15随机＋5行为，人口301，行情81/82/83。每格跑8640tick常态及同样长度注资路径，在2160/8640tick截取；不丢预热，不重置状态。24小时路径的6小时前缀与真正运行6小时在因果模拟下相同。共60路径、518400tick。

央行仍在1000tick（2小时46分40秒）常规成交后向池本币侧加10万。到6小时只剩3小时13分20秒，到24小时剩21小时13分20秒；主结局取局末180tick（30分钟）均价。原始回落100%对应注资前价格；配对回落100%对应同期无注资价格，两者分开。

主要观察：每账户完成轮数、零完成账户、完成轮持有时长、期末未完成轮次及年龄、最长无成交、行为成交占比、到达峰值及钱包裁剪。持有时长仅为已完成样本，不能代替所有轮次的等待时间。市场相关使用全局含零收益、无预热序列，短样本结果仅描述，不能继承旧长路径的稳健性结论。注资跳点不用于常态ACF。

不预设每小时必须几轮，不事后追加最优阈值，不因全行为组停滞加入超时、补钱或价格锚。更短持有不等于更像人、更公平或可盈利；全行为容量对恢复旧价的限制依旧存在。

重现：`python -m research.fx.episodes.session.run`，随后`python -m research.fx.episodes.session.report`。旧版本及旧结果保留，原参数常态前缀逐字段核对。结果见[实验报告](results/report.md)。更短线的后续结果独立保存在[rapid](../rapid/README.md)。
