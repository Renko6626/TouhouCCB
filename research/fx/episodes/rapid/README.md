# 更短线的参数探索

用户在首轮6/24小时试验后要求继续缩短持仓。继续复用原模拟器，不增加策略。固定热度tau1000、每轮100外币及其他设置，把止盈止损依次设为±0.125%、±0.0625%、±0.025%，移动启动和回撤均为该绝对值的一半。与原到达强度基准1相比，另试现有mean_arrivals=3；这会提高所有账户的查看/下单机会，也提高随机背景成交，不能称为只改变行为账户的监控频率。

只用移动退出；20行为与15随机＋5行为，行情81/82/83、人口301。6组×2构成×3种子×常态/注资，共72路径、622080tick。每条8640tick，统计2160/8640的开局前缀，无预热；注资仍在第1000tick向池本币侧加10万。参数在本轮运行前冻结，未事后追加搜索。

很低的退出阈值可能对一两笔订单的冲击敏感；更快或更多完成轮不等于更像人、可盈利或适合玩家。检查短持仓同时的完成/未完成状态、反向相关、成交占比、裁剪、强度和实际到达峰值。全行为等待问题不靠补钱、超时或外部锚掩盖。手续费仍为0，未验证真实收费下的可行性。

参照[上一轮局长实验](../session/results/report.md)。运行命令：`python -m research.fx.episodes.rapid.run`，随后`python -m research.fx.episodes.rapid.report`。

用户随后明确目标：典型持仓5～15分钟，5%指单次典型大事件。原到达率、止盈止损±0.125%（移动启动/回撤各0.0625个百分点）记为[候选参数](candidate-5-15min.json)，未替换旧基线。详见[完整报告](results/report.md)与[单次+5%事件检查](results/event5/report.md)。候选常态均值约8分钟；事件后热度显著加速交易，不能保证全局都在5～15分钟。事件检查只覆盖上涨，不推断下跌对称性或连续事件。
