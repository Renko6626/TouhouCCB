# FX 短认证 session 修复后的本机压测

结论：本机 100 人、200 SSE 的两分钟只读和五分钟正常交易完成，正常阶段 748 笔成功成交、5762 个 HTTP 请求全部成功，成交 P99 为 213.285ms。高负载仍有上限：100 人名义 25 次交易尝试/s 的加压阶段因成交 P99 >2 秒自动中止。两轮均未出现原有连接池耗尽。

目标：`http://127.0.0.1:18543`。真实 PostgreSQL 14、单 Uvicorn worker、应用池 10+20，单独采样连接不占应用池。代码采用干净的 bde43b0 后端快照，仅替换本次修复的 user_trading.py；依赖来自项目 backend/venv。完整应用 lifespan 和业务后台服务正常启动。

每轮独立空库和普通测试账户，初始现金 100000；源池金储备 1000000、外币储备 200000，费率 0，允许融资及做空，角色比例 60/20/20。与线上池子初始经济状态不同，且无线上网络、Nginx、CDN 和宿主机资源限制，结果仅说明本机表现。
