# FX 前端交互样稿

运行 `npm run dev` 后访问 `/fx-preview`，免登录。

- 独立于真实 `/fx` 页面，所有交易只修改页面内存，刷新即重置。
- 支持看涨做多、看跌做空、调整交易规模与目标账户杠杆、模拟成交、减仓和平仓。
- 顶部选择空仓、多头、空头账户；也可用 `?position=long` 或 `?position=short` 打开对应示例。
- 沿用现有黑白风格、涨绿跌红色板。手机优先展示下单区。
- 杠杆按全账户参考敞口 / 净值展示，快捷档位只是目标；费用使预计成交后的倍数略有偏差。金额没有被划入单笔保证金账户。
- 做多展示现金与借款拆分；做空展示借币数量与锁定卖出所得。同币种已有相反方向持仓时提示先平仓。
- 固定参考价格为 0.2，示例费用为 0.2%，示例开仓门槛为 1/19。均不代表线上配置。
- 不模拟真实 AMM 价格影响、利息、强平、交易限制或并发。模拟数值使用 JavaScript Number，不能作为生产金额计算逻辑。

这是用于确认交互与视觉的临时样稿。后续“借款并买入”原子接口与真实数据接入需要另外设计和验证。
