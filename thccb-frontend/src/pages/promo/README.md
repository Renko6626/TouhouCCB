# 宣传用模拟交易页

在前端目录运行 `npm run dev`，访问 `/promo`。不需要登录或启动后端。

- 使用项目现有的黑白工业风和涨绿跌红色板。
- 假行情、初始持仓和成交记录在 `data.ts` 中，可直接修改。
- K 线使用固定随机种子和活动日期，刷新后画面保持一致。
- 支持切换角色、K 线周期、价格走势，以及模拟买卖和重置。
- “导出 K 线”下载当前图表 PNG；整页可使用浏览器截图工具。
- 模拟金额按价格乘份额计算，手续费为 0.2%，持仓市值和浮盈为参考值；不模拟实际 LMSR 滑点及清算规则。
- 所有交易只修改页面内存，刷新即重置，不调用交易接口、不写入账户。
